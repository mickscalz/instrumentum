# The Recorder Implementation Plan

> **For agentic workers:** one task per agent, in its own worktree and branch (`rec-tN`, off `recording`). Steps use checkbox (`- [ ]`) syntax. Do not fetch any website: everything needed is in the repo. You cannot compile here; push your branch and read CI (`gh api "repos/mickscalz/instrumentum/actions/runs?branch=<branch>&per_page=1"`, then the `test-report` notice in the run's annotations/logs), and fix until the three test jobs are green. Touch only the files your task lists.

**Goal:** record what is played as audio, overdub layers, play along with a track file or the Mac's sound through BlackHole, and record any input device as a live source.

**Architecture:** pure session, naming, mixing and latency logic in `InStrumCore/Recording`; three new buses, a tap fan-out, a stem writer, layer players and an input-capture bridge in `InStrumAudio`; a small state machine and a bottom strip in `InStrumApp`. With the Recorder idle and no source chosen, the engine graph and its output are exactly as today.

**Tech stack:** Swift 5.10, AVFoundation (`AVAudioEngine`, `AVAudioFile`, `AVAudioPlayerNode`, `AVAudioSourceNode`, `AVAudioConverter`), Core Audio HAL properties, SwiftUI. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-16-recorder-design.md` (read it first; section numbers below refer to it).

## Global constraints
- macOS 13, Intel. No new packages.
- Audio-thread and tap code: no allocation, locks held only for a pointer swap (`OSAllocatedUnfairLock`, as `AudioEngine.Shared` does), no file or Objective-C messaging in a render block.
- Nothing is written to disk before Record is pressed.
- Stems: WAV, 24-bit, stereo, output sample rate. Mix: `Mix.m4a` AAC 256 kbps; optional `Mix.wav`.
- Limits: 8 layers; 3600 s per layer; refuse to start under 2 GB free; stop under 500 MB.
- Mix headroom: if the summed peak exceeds −1 dBFS (0.891), scale the whole mix by one gain to 0.891; never scale up.
- Timing nudge −100…+100 ms, default 0. Capture buffer target 10 ms.
- Test assertions are simple statements over named locals (no chained map/zip/max inside an `XCTAssert`). Never read main-actor state in a default argument.
- Taps do not run in offline manual rendering: audio tests drive the recorder by feeding it the buffers `renderOffline` returns.
- Older `settings.json` files must load (use `decodeIfPresent` with the defaults, as `AppSettings` does).
- Do not touch `AutoQuality`, `RenderScale`, `ThemeCanvas`, `GPUClock`, any renderer, or any DSP engine.

## Review focus
1. **Bluetooth output (150 ms+ latency):** overdubs must still line up; Task 1 `testInstrumentStemMovesEarlierByOutputLatency`, Task 3 `testOverdubLandsWithinOneSample`.
2. **The app's output is the device it listens to:** no howl; Task 4 `testPlayThroughIsMutedWhenInputIsTheOutput`.
3. **The app dies with the Mac's output switched to BlackHole:** next launch restores it; Task 4 `testCrashMarkerRestoresTheMacsOutput`.
4. **Disk fills or the output device vanishes mid-pass:** the layer is kept, never a corrupt header; Task 2 `testAStoppedWriterLeavesAReadableFile`, Task 5 `testLowDiskStopsAndKeeps`.
5. **A mono or 16-channel input, or one at another sample rate:** Task 4 `testChannelPairsAndMonoCentre`, `testCaptureResamplesToTheEngineRate`.

```swift
public final class StemRecorder {
    public init(sampleRate: Double, capacitySeconds: Double = 2)        // preallocated SPSC ring per stem
    public func begin(_ stems: [(kind: StemKind, url: URL)], atSampleTime start: Int64) throws
    /// Tap thread. Frames before `start` are dropped; a gap in sample time is filled with silence. Never allocates.
    public func feed(_ kind: StemKind, left: UnsafePointer<Float>, right: UnsafePointer<Float>, frames: Int, sampleTime: Int64)
    public func end() -> [StemKind: Int]                                // frames written per stem; files closed and readable
    public var isRecording: Bool { get }
    public var seconds: Double { get }
    public var overruns: Int { get }                                    // ring overflows (0 in every test)
    public func peak(_ kind: StemKind) -> Float                         // since last read, for meters
}
extension AudioEngine {
    public var playAlongBus: AVAudioMixerNode { get }                    // attached lazily, → main mixer
    public var liveInputBus: AVAudioMixerNode { get }
    public var layersBus: AVAudioMixerNode { get }
    public var playAlongVolume: Float { get set }; public var liveInputVolume: Float { get set }; public var layersVolume: Float { get set }
    public var recorder: StemRecorder? { get }
    public func beginRecording(_ stems: [(kind: StemKind, url: URL)]) throws -> Int64    // start sample time = now + 2 buffers
    public func endRecording() -> [StemKind: Int]
    public var recordingBusesAttached: Bool { get }                      // false until one is first used
    /// Offline tests: feed what `renderOffline` returned as the instrument stem.
    func feedOffline(_ buffer: AVAudioPCMBuffer, kind: StemKind, sampleTime: Int64)
}
```
A writer thread (one `Thread`, QoS `.utility`) drains the rings every 20 ms into `AVAudioFile`s (settings: linear PCM, 24-bit, interleaved, 2 channels). Sleep gain and master volume are downstream of the instrument bus's tap and never reach a stem.

```swift
public struct InputDevice: Equatable, Identifiable, Sendable { public let id: AudioDeviceID; public let uid: String; public let name: String; public let channels: Int; public var isBlackHole: Bool; public var isBuiltInMicrophone: Bool }
public struct ChannelChoice: Codable, Equatable, Hashable, Sendable { public var left: Int; public var right: Int?   // 0-based; right nil = mono, centred
    public static func choices(channels: Int) -> [ChannelChoice]        // 1, 2, 1+2, 3, 4, 3+4, … ; the default is 1+2 when channels ≥ 2, else 1
    public var label: String }
public enum InputDevices { public static func all() -> [InputDevice]; public static func blackHole() -> InputDevice?; public static func latency(_ id: AudioDeviceID) -> RecordingLatency.Device }
/// SPSC ring with a drift-following read: the reader resamples by a ratio within ±0.5% that steers the fill toward `targetFrames`.
public final class CaptureRing { public init(capacityFrames: Int, targetFrames: Int)
    public func write(left: UnsafePointer<Float>, right: UnsafePointer<Float>, frames: Int)
    public func read(left: UnsafeMutablePointer<Float>, right: UnsafeMutablePointer<Float>, frames: Int)   // silence, not garbage, on underrun
    public var fillFrames: Int { get }; public var underruns: Int { get }; public var overruns: Int { get } }
public final class InputCapture {                                       // an input-only AVAudioEngine on `device`, → CaptureRing → AVAudioSourceNode
    public init(device: InputDevice, channels: ChannelChoice, engineRate: Double, targetMs: Double = 10)
    public func start() throws; public func stop()
    public var sourceNode: AVAudioSourceNode { get }                    // attach in the main engine
    public var gainDB: Float { get set }                                // −24…+24
    public var peak: Float { get }; public var clipped: Bool { get }
    public var onStopped: (() -> Void)?                                 // device unplugged
}
public enum InputSlot { case playAlong, liveInput }
extension AudioEngine {
    public func setInput(_ slot: InputSlot, device: InputDevice?, channels: ChannelChoice, hearIt: Bool) throws   // nil removes
    public func setHearIt(_ slot: InputSlot, _ on: Bool)
    public func inputIsTheOutput(_ slot: InputSlot) -> Bool             // same device UID as the one really playing
    public func inputPeak(_ slot: InputSlot) -> Float
    public func inputLatency(_ slot: InputSlot) -> RecordingLatency.Device?
}
public struct MacOutputSwitch {                                         // the Mac's default output ↔ BlackHole
    public init(get: @escaping () -> String?, set: @escaping (String) -> Bool, marker: UserDefaults = .standard)   // device UIDs; injected for tests
    public static var live: MacOutputSwitch                             // kAudioHardwarePropertyDefaultOutputDevice
    public mutating func switchTo(_ uid: String) -> String?             // returns the previous UID and stores the marker "recorder.restoreOutputUID"
    public mutating func restore()                                      // clears the marker
    public mutating func restoreAfterCrashIfNeeded() -> Bool
}
```
