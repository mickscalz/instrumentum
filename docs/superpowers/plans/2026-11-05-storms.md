# Sets 17 & 18 ("Storms": Supercell Sky, Lightning Plains) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Model ladder (working rules, 5 Nov):** build tasks on Opus for anything that shapes looks or sound (DSP, renderers, sky, weather, ambience, cards) and Sonnet for plumbing, presets from finished tables, test-only fixes and docs; Fable writes and reviews only. Two agents at a time at most.

**Goal:** Ship Sets 17 and 18, each with one of everything (world, visual, instrument, sky feature, weather, ambience, mood, credit): Endless Rise and Single Note Grand; anvil crawlers and sheet lightning; Gust front and Virga; the storm and plains ambience families; the shared wind field.

**Spec:** `docs/superpowers/specs/2026-11-05-storms-design.md` (section numbers below refer to it).

**Architecture:** the engines are C++ behind the existing C API (`ShepardRise.hpp` header-only on `AnalogVoice.hpp`; the grand on Felt Glass's string core plus the formant helper). The sky features are seeded Core machines drawn analytically. The weathers go through `WeatherKind`, the shared weather layer and `WeatherAmbience`. The worlds follow the Core-model, App-renderer split and adopt `ExcitementAware`.

**Tech stack:** Swift 6.1 (Swift 5 mode), SwiftUI, Metal (MSL in Swift strings), C++17 (`-O2`), SwiftPM, XCTest.

**Builds on:** the integration branch (`sets-13-14`, which carries Sets 7–12, Small Wins so far and Fire & Neon's Excitement core). Cut `storms` from it; merge it in again whenever it moves. **Before each task:** `git fetch` and check nobody else has pushed a branch for the same task.

## Review focus
1. **The riser's seam.** As φ wraps, no click and no loudness step (±0.5 dB). Pinned in Task 2.
2. **The drop twice.** A second drop within 2.5 s must not restart the thump or the collapse; it is ignored until the release envelope passes 0.2. Pinned in Task 2.
3. **Forced morph and real pressure.** When the drop ends, Morph returns to the player's aftertouch over 250 ms, never snapping. Pinned in Task 4.
4. **Thunder after a switch.** Queued thunder is cleared on world switch and panic; nothing fires in the next world. Pinned in Task 8.
5. **Flash budget under the worst case.** Lots moments + Often crawlers + Often sheet + a Core-stage supercell for 60 s never exceeds 3 flashes a second or a red flash over 20%. Pinned in Tasks 7 and 10.
6. **Old saves.** Settings without the two sky modes; weather lists without `.gustFront`/`.virga`; worlds without `distance`; a set store with fewer sets. Pinned in Tasks 6 and 13.
7. **Smooth.** Both renderers ≤ 2.5 ms a frame at 1 MP on the Intel Mac (measured by the preview job's timing output). Pinned in Tasks 10 and 12.

## Rulings recorded while planning
- **Tension and drop reach the engine as atomics** set from the Core's Excitement step on the main thread, read once per control block. Cost if wrong: none.
- **The wind field is sampled per grass row** (48 rows on High, 24 on Smooth), never per pixel. Cost if wrong: the rows are a dial.
- **Crawlers live in the cloud layer**, not `skyRadiance`, so they sit on the cloud base and reflections don't need them. Cost if wrong: 16 rows move.
- **Supercell Sky's weather is the supercell event itself;** `WorldWeather` maps the picker's stage to the event's phase. Cost if wrong: one mapping.
- **RED by construction**, as always.
